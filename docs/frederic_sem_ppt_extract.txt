=== SLIDE 16 ===
Rules for determining the model parameters
Rule 1: All the variances of the independent variables are parameters
Rule 2: All covariances between independent variables are parameters
Rule 3: All load factors between latent and its indicators are parameters
Rule 4: All regression coefficients between observed or latent variables are parameters
Rule 5: (i) The variances of dependent variables, (ii) the covariance between dependent variables and (iii) the covariance between dependent and independent variables, are never parameters (are explained by other parameters of the model)
Rule 6: For each latent variable must be set its metric:
For independent latent two ways:
Set its variance set to a constant (usually 1)
Fix a load factor between latent and its factor (usually 1)
For the latent dependent only one way: fix a coefficient between it and one of the observed variables to a constant (usually 1)

=== SLIDE 22 ===
Variance and covariance laws
Law 1:
	Cov (X,X) = Var (X)

Law 2:
	Cov (aX + bY, cZ + dU) =
	ac Cov(X,Z) + ad Cov(X,U) + bc Cov(Y,Z) + bd Cov (Y,U)

Law 3:
	Var(aX + bY) = a2 Var(X) + b2 Var(Y) + 2ab Cov (X,Y)

Law 4: (if X and Y are uncorrelated) 
	Var(aX + bY) = a2 Var(X) + b2 Var(Y)

=== SLIDE 30 ===
Identification of the model
Just identified model: number of data variances and covariances equals the number of parameters. The model yields an unique solution for all parameters, but scientifically it is not interesting because without degrees of freedom it never can be rejected.

Overidentified model: positive degrees of freedom. It allows to reject the model. It allows to analyze the discrepancy between S and ∑ , thereby rendering it of scientific use.
The aim in SEM then is specify overidetified models

Underidetified model: infinite number of solutions. No useful at all…

=== SLIDE 31 ===
The logic of the model fitness
Get the estimated parameters to minimize the difference between S and Σ
Set a Fit function F (S, Σ) that measures the difference: F = f (S - Σ) = f (parameters)
An iterative algorithm minimizes F
Rule of "thumb" to determine adequate sample size, 10 times the number of parameters
The statistic T = (n-1) * Fmin is defined 
"N" is sample size
F is the minimum of the fit function
"T" is asymptotically distributed as χ2 with the same degrees of freedom that the model
If the model is correct, it is expected that the differences between S and Σ are small: the value of χ2 will be low and high probability (p-value> .05)

=== SLIDE 32 ===
The logic of the model fitness
Estimation methods to calculate parameters and hence the Chi-squared:
method of Maximum Likelihood (ML)method of Generalized Least Squares (GLS)method of Unweighted Least Squares (ULS)

The c2 statistics are shown as:
c2 ML = (n -1) [Tr (Så-1) - (p + q) ln | å | - ln | S |
c2 GLS = ( n - 1) [0,5 Tr ((S - å) S -1) 2]
c2 ULS = (n- 1) [0,5 Tr ((S - å)2)]

Where:
Tr= Trace
Ln= natural logarithm
t = number of estimated parameters.
n = number of cases.
p + q = number of observed variables
fd (freedom degrees) = 0,5 (p + q) (p + q + 1) – t
S = Matrix of observed covariances (initials)
å = Matrix of covariances generated.

=== SLIDE 33 ===
Absolute fit measures:
Test χ2 and significance level (p > 0.05)
Test χ2Satorra-Bentler and significance level (p > 0.05) : works well in a variety of 						 distribution situations
Goodness of Fit Index (GFI) (High > 0.9 )
Root Mean Squared Residual (RMSR) (low)
Root Mean Squared Error of Approximation (RMSEA) (< 0.08)

Incremental fit measures (it compares with respect the null model):
Bentler Bonnet Normed Fit Index (NFI o Δ) (> 0.9)
Bentler Bonnet Non Normed Fit Index (NNFI o Δ) (> 0.9)
Adjusted Goodness of Fit Index (AGFI) (> 0.9)
Comparative Fit Index (CFI) (> 0.9 or even 0.95)

Parsimonious fit measures (quality of fit with respect the number of estimated coefficients):
Normed Chi-Square (χ2/ d.f. ) (up to 5)

RECOMMENDED SAMPLE SIZE: At least 5 times the number of free parameters to be estimated

=== SLIDE 34 ===
The logic of the model fitness
Assessing model fit
Null hyp: there will be no difference between the model and the data
Or the model will fit the data
Alternative hyp: there will be a difference between the model and the data
Or the model will not fit the data
So, if the model fits well there will be no significant difference between the model and the data
Note: chi-square test is sensitive to large N
